# Releases

One folder per release, run by [Lattice](https://github.com/Polymarket/lattice).
`.lattice.json` at the repository root points Lattice here, so `lattice release register <name>`
resolves `script/releases/<name>/release.json`.

How to write one: `lattice help authoring` (and `lattice help manifest` for every field), plus
*Releases (Lattice)* in the root `CLAUDE.md` for what is particular to this repository.
